# 🚀 Alok Verma - 3D Animated Portfolio

A visually immersive and interactive **personal portfolio website**, designed to showcase projects and skills through a dynamic 3D experience powered by GSAP, ScrollTrigger, and Three.js.

## ⚙️ Core Technologies & Libraries
- **HTML5, CSS3, JavaScript (ES6+)**
- **Three.js** — 3D rendering and scene graph
- **GSAP + ScrollTrigger** — High-performance scroll-based animations
- **Blender** — 3D modeling, lighting & texture baking

---

## ✨ Key Features
- 🎞️ **Scroll-Based 3D Animations** — Cinematic storytelling as you scroll
- 🎭 **Complex Animation Timelines** — GSAP-orchestrated sequences
- 📱 **Responsive & Performant** — Optimized for various devices
- 🎨 **Modern UI/UX** — Clean interface complementing 3D visuals
